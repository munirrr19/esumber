# Menyumbang

Terima kasih kerana berminat menambah baik eSumber.

## Cara bermula

1. Fork repo ini dan buat branch baharu.
2. Pasang dan jalankan secara setempat (lihat [README](README.md)).
3. Pastikan ujian lulus: `npm test`.
4. Hantar Pull Request dengan penerangan ringkas tentang apa yang diubah dan sebabnya.

## Panduan

- Ubahan kecil dan fokus lebih mudah disemak.
- Tambah ujian dalam `test.js` jika mengubah logik tempahan atau API.
- Jangan sertakan data sebenar (nama, domain, ID pangkalan data).
- Antara muka kini dalam Bahasa Melayu. Sumbangan terjemahan amat dialu-alukan.

## Idea yang dialu-alukan

- Terjemahan antara muka ke bahasa lain
- Mod gelap
- Penambahbaikan kebolehcapaian (accessibility)
- Dokumentasi dan tangkapan skrin
